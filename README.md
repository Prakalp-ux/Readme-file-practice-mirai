# Student Learning Portal
## Introduction
Hello there, I am Prakalp Dwivedi. I am a student of Mirai School Of Technology.
## About the project
I am creating a website on __chess tutorial__ in which anyone can learn chess through scrolling the web at the cost of ~~100₹~~ your time for free. 
*In this website I will convert a newbie player of chess to an average chess player. As to become above average you will need to play chess in real life with person.*
## Project Features :
- Learning basic moves of pieces.
- Resolving basic problems that came up in a game.
- Get support to create your international chess id.
- Know about your city tournaments.
